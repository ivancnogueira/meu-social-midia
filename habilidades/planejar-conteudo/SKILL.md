# Planejar conteúdo

Use esta habilidade para organizar ideias em uma sequência editorial.

## Leitura inicial

Leia `conteudos/perfil-da-marca.md`, `conteudos/pilares-de-conteudo.md`, `conteudos/banco-de-ideias.md` e, quando existir, `conteudos/campanhas.md`. Não preencha lacunas de marca com suposições; aponte o que precisa ser decidido.

## Planejamento

Relacione cada sugestão a um pilar, objetivo, formato, mensagem central, CTA e estado. Equilibre formatos e intenções, sem criar um calendário excessivo para a capacidade informada pelo usuário. Priorize campanhas com condições confirmadas.

## Saída

Entregue uma tabela ou arquivo Markdown com data ou ordem sugerida, brief resumido, recursos necessários e próximo passo de revisão. Marque tudo como rascunho até que a pessoa aprove cada item.
