# Criar post de anúncio

Use esta habilidade para preparar um criativo estático destinado a uma campanha paga.

## Brief obrigatório

Confirme objetivo de campanha, público, oferta, CTA, destino e condições antes de escrever. Se algum deles não estiver definido em `conteudos/campanhas.md`, solicite a informação em vez de assumir.

## Entrega

Forneça:

- ângulo e mensagem principal;
- texto curto para a arte;
- direção visual usando recursos autorizados;
- legenda ou texto de apoio, quando necessário;
- pontos de verificação de política e de comprovação da oferta.

Não use atributos pessoais sensíveis, promessas irreais, urgência falsa ou dados não confirmados. A aprovação de um rascunho não autoriza veiculação nem publicação.

Use o tipo `post-anuncio` no JSON de entrada, gere os artefatos com `npm run criar-conteudo -- ARQUIVO` e revise o PNG local. O sistema prepara o criativo; ele não cria nem ativa campanhas em uma conta de anúncios.
