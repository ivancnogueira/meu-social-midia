# Criar carrossel

Use esta habilidade para planejar ou montar um carrossel de Instagram.

## Antes de criar

Leia o perfil do negócio, os pilares e o briefing. Defina objetivo, público, ideia central e CTA. Se o assunto depender de uma informação não confirmada, pare no brief e peça essa confirmação.

## Estrutura

- Crie uma capa que deixe claro o benefício ou a tensão principal.
- Faça cada slide avançar uma única ideia, com leitura rápida e hierarquia visível.
- Inclua fechamento e CTA coerentes com o objetivo.
- Entregue também legenda e uma especificação de recursos próprios ou autorizados.

Salve o briefing em JSON seguindo `exemplos/publicacao-exemplo.json`, execute `npm run criar-conteudo -- ARQUIVO` e depois `npm run atualizar-vitrine`. Confira os PNGs 1080x1350 e o preview antes de criar a tarefa de aprovação.
