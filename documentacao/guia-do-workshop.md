# Guia do workshop

## Resultado esperado

Cada participante termina com o perfil do próprio negócio preenchido, uma ideia estruturada, um post individual e um mini-carrossel de cinco slides exportados e conferidos em preview local.

## Roteiro sugerido

1. Verificar Node.js 20+ e Git.
2. Abrir o projeto e executar `npm run configurar`.
3. Responder nicho, público, oferta, tom e CTA.
4. Revisar os arquivos em `conteudos/` e registrar uma ideia própria.
5. Executar `npm run diagnosticar` e discutir a configuração manual da Meta.
6. Usar as habilidades internas para transformar a ideia em um JSON de publicação e gerar as artes com `npm run criar-conteudo`.

## Trial sem plano pago

O exercício deve usar texto, fotos próprias ou layouts locais. Não prometa geração recorrente de imagens por IA sem que a pessoa tenha acesso e créditos compatíveis.

## Segurança

Não compartilhe `.env`, tokens, dados de clientes ou capturas contendo informações privadas. Nenhuma publicação real é feita neste workshop.
